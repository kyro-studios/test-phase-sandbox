# プロジェクトの背景

## 目的と背景

Coding Agent の仕組み (テンプレート) の動作を確かめるための、確認用のリポジトリである。アプリケーションそのものに利用者はおらず、仕組みが段階ごとに意図どおりに動くことを確かめるために、小さな機能を順に作る。

## 規模

- 想定する利用者の数: 0 人 (仕組みの開発者が動作を確かめるだけ)
- 見積もりの総コスト (トークン量): 未定。1 つの機能を、できるだけ少ない費用で最後まで通したい
- 総工数: 未定
- 期限: なし

## 方針

- 優先順位: C > D > Q
- 品質の水準: 試作。要件を満たしたことの確認に要る振る舞いだけを、受け入れテストで確かめる。入力のバリエーションの網羅や、要件に書かれていない状況への備えは行わない

## そのほかの制約

なし
