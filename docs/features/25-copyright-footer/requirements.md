# 要件定義書: 著作権の表記のフッター

## 1. 目的

アプリケーションの著作権者を、利用者がどの画面からでも確かめられるようにする。そのため、すべての画面の下部に、著作権の表記のフッターを表示する。

## 2. 範囲

### 2.1 この機能で扱うこと

- すべての画面に共通して表示するフッター
- フッターに表示する著作権の表記

### 2.2 この機能で扱わないこと

- 利用規約やプライバシーポリシーなど、ほかのページへのリンク
- 多言語での表示の切り替え
- 画面ごとに、フッターを表示するかどうかを切り替えること
- サーバーの側の変更

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 利用者 | アプリケーションを使う人。ログインしているかどうかは問わない |
| フッター | 画面の下部に置く、すべての画面に共通の領域 |
| 著作権の表記 | 著作権の記号、年、著作権者の名前を並べた文字列 (例: `© 2026 Kyro Studios`) |
| 著作権者 | Kyro Studios |

## 4. 機能要件

- FR-1: アプリケーションのすべての画面の下部に、フッターを表示する
- FR-2: フッターには、著作権の表記 `© <年> Kyro Studios` を表示する
- FR-3: 著作権の表記の年は、画面を開いたときの、利用者の端末の日付の年 (西暦の 4 桁) にする
- FR-4: 画面の内容が短く、画面の高さに満たないときも、フッターは画面の下端に表示する。画面の内容が長いときは、内容の後に表示する

## 5. 非機能要件

- NFR-1: フッターを表示するために、サーバーの API を呼び出さない。サーバーに接続できないときも、フッターを表示するため
- NFR-2: フッターは、支援技術 (スクリーンリーダーなど) から、画面のフッターの領域として認識できるようにする

## 6. 前提

- 利用者は、ブラウザーでアプリケーションを使う
- この機能は、このリポジトリの 2 つ目の機能で、アプリケーションのプロジェクトの土台はすでにある
- この機能は、仕組みの動作確認のための小さな機能である
