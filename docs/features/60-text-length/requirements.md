# 要件定義書: 入力した文の文字数を表示する

## 1. 目的

利用者が文を入力すると、その文の文字数を画面に表示する。文字数はサーバーが数え、画面はその結果を表示する。文が空のときや長すぎるときは、利用者に誤りを伝える。

この機能は、仕組みの動作確認 (CI の失敗の検知と修正) のための小さな機能である。

## 2. 範囲

### 2.1 この機能で扱うこと

- 文を入力して、文字数を表示する画面
- 文の文字数を数える、サーバーの API
- 文の入力の誤り (空、長すぎる) を伝えること

### 2.2 この機能で扱わないこと

- 文や文字数の保存 (履歴の表示を含む)
- ログインや、利用者ごとの表示の切り替え
- 単語の数や行の数など、文字数のほかの数え方
- 既存の画面 (挨拶の画面など) からの導線

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 利用者 | アプリケーションを使う人。ログインは要らない |
| 文 | 利用者が入力する文字列。前後の空白も含めて、入力したとおりに扱う |
| 文字数 | 文の文字の数。Unicode のコードポイントの数で数える (例: `あいう` は 3、`😀` は 1) |

## 4. 機能要件

- FR-1: 文字数の画面に、文の入力欄と、文字数を求めるボタン (`数える`) を表示する
- FR-2: 利用者が文を入力してボタンを押すと、`<文字数> 文字` の形で文字数を画面に表示する (例: `3 文字`)
- FR-3: 文字数は、サーバーの API が文から数える。画面は、API が返した文字数をそのまま表示する
- FR-4: 文が空 (0 文字) のときは、`文を入力してください` と表示し、文字数は表示しない。空白だけの文は空とみなさず、空白も 1 文字として数える
- FR-5: 文の文字数が 201 文字以上のときは、`文は 200 文字以内で入力してください` と表示し、文字数は表示しない。200 文字ちょうどは受け付ける
- FR-6: サーバーの API も、FR-4 と FR-5 と同じ決まりで文を確かめる。画面を通さずに API を呼んだときも、誤りの文からは文字数を返さず、誤りであることと、FR-4 か FR-5 と同じ文言を返す
- FR-7: もう一度ボタンを押したときは、前に表示した文字数や誤りを、新しい結果で置き換える

## 5. 非機能要件

- NFR-1: 文や文字数を、サーバーにもブラウザーにも保存しない
- NFR-2: 文の入力欄は、支援技術 (スクリーンリーダーなど) から、何を入力する欄か分かるようにする。誤りの表示も、支援技術から読み上げられるようにする
- NFR-3: サーバーに接続できないときは、`文字数を取得できませんでした` と表示する
- NFR-4: この機能は DB を使わない。文字数の API は、DB に接続せずに、文の確認と文字数の計算を行う

## 6. 前提

- 利用者は、ブラウザーでアプリケーションを使う
- この機能は、このリポジトリの 4 つ目の機能で、アプリケーションのプロジェクトの土台はすでにある
- この機能は、仕組みの動作確認のための小さな機能である
